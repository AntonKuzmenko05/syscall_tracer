# syscall_tracer
 Розробка Інструмента профайлінгу системних викликів (Syscall Tracer, Linux)

 2. Розробка Інструмента профайлінгу системних викликів (Syscall Tracer, Linux)Мета: Навчитись відстежувати, які системні виклики (syscalls) робитьпевнийпроцес і скільки часу він на них витрачає. Базовий функціонал: Потрібно створити утиліту, яка запускаєдовільнупрограму та відстежує всі системні виклики, які вонавиконує,використовуючи системний виклик ptrace (це те, що використовуєутилітаstrace в Linux). Вимірювання часу (CPU): Для кожного системного викликунеобхідновиміряти час його виконання (тривалість міжвходомуядротаповерненням) з високою точністю, використовуючиінструментипрофайлінгу Linux (наприклад, clock_gettime з високоюроздільноюздатністю або навіть за допомогою інструкцій CPU(використовуючиrdtsc— Read Time-Stamp Counter)). Звіт: Утиліта повинна генерувати звіт, який показує:
Загальну кількість викликаних syscalls. Топ-5 найчастіше викликаних syscalls. Топ-5 syscalls, які зайняли найбільше сумарного часу CPU. Прикладна цінність: Системна діагностика (Debugging та Performance),виявлення вузьких місць, аналіз поведінки.
